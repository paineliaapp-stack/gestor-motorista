Política de Privacidade

Última atualização: junho de 2026

🔒 Resumo direto: seus dados financeiros são seus. Não vendemos, não compartilhamos com anunciantes, não usamos para treinar modelos de IA de terceiros. Usamos apenas para prestar o serviço que você contratou.

1. Quem somos

Painel.IA é um serviço de gestão financeira para motoristas de aplicativo. Esta política explica como coletamos, usamos e protegemos suas informações, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados que coletamos

Dados que você fornece:

  • Email e nome (via login Google)
  • Lançamentos financeiros (ganhos, despesas, contas) inseridos via chat
  • Metas financeiras e configurações de perfil
  • Informações sobre plataformas que você utiliza (Uber, 99, iFood, etc.)

Dados coletados automaticamente:

  • Cidade aproximada (para previsão do tempo — nunca localização exata)
  • Dados de uso do app (quais funcionalidades você acessa)
  • Informações do dispositivo (iOS/Android, versão do navegador)

3. Como usamos seus dados

  • Para prestar o serviço: processar seus lançamentos, calcular lucro, gerar relatórios e responder via chat.
  • Para a IA: suas mensagens são processadas pela API do Google Gemini para gerar respostas do Gestor. O Google processa os dados conforme sua própria política de privacidade. Não usamos seus dados para treinar modelos.
  • Para comunicação: enviar emails sobre o status da sua assinatura (boas-vindas, aviso de expiração, confirmação de pagamento).
  • Para melhorar o produto: analisar padrões de uso de forma agregada e anônima. Nunca analisamos dados individuais identificados.

4. Compartilhamento de dados

Seus dados nunca são vendidos. Compartilhamos apenas com:

  • Google Gemini: mensagens do chat para geração de respostas da IA.
  • MercadoPago: email para processar pagamentos de assinatura.
  • Resend: email para envio de comunicações transacionais.
  • Supabase: armazenamento seguro de todos os dados do app.
  • Autoridades: apenas se exigido por ordem judicial.

5. Segurança

  • Toda comunicação é criptografada via HTTPS/TLS.
  • Autenticação via Google OAuth — não armazenamos senhas.
  • Acesso aos dados restrito a você — validamos sua identidade em cada requisição.
  • Banco de dados hospedado no Supabase com criptografia em repouso.

6. Seus direitos (LGPD)

Você tem direito a:

  • Acesso: solicitar uma cópia de todos os seus dados.
  • Correção: corrigir dados incorretos.
  • Exclusão: solicitar a exclusão de todos os seus dados.
  • Portabilidade: exportar seus dados em formato legível.
  • Revogação: revogar consentimentos dados anteriormente.

Para exercer qualquer desses direitos: privacidade@painelia.app

7. Retenção de dados

Mantemos seus dados enquanto você tiver uma conta ativa. Em caso de cancelamento, seus dados ficam disponíveis por 30 dias para exportação. Após esse prazo, são excluídos permanentemente dos nossos servidores.

Backups podem conter dados por até 90 dias adicionais antes da exclusão completa.

8. Cookies e armazenamento local

Utilizamos localStorage (armazenamento local do navegador) para manter sua sessão ativa e preferências do app. Não utilizamos cookies de rastreamento nem pixels de publicidade.

9. Menores de idade

O Painel.IA é destinado a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Se identificarmos uma conta de menor, ela será encerrada.

10. Alterações nesta política

Podemos atualizar esta política periodicamente. Alterações significativas serão comunicadas por email com pelo menos 15 dias de antecedência.

11. Contato

Encarregado de Proteção de Dados (DPO): privacidade@painelia.app

Para dúvidas gerais: contato@painelia.app
